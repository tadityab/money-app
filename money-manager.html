⚡ Auto Setup
🤖
Automatic SMS Tracking
iOS Shortcuts will auto-detect your bank messages and open this app pre-filled. You only tap Save!
✅ How it works after setup:
1. Bank SMS arrives → Shortcut triggers automatically
2. App opens with transaction pre-filled
3. You tap Save — done! (1 tap only)
Step 1 — Host App Online (One Time)
1
Open Safari on iPhone
Go to this website — it's free, no account needed
tiiny.host
2
Upload money-manager.html
Tap Upload → select the HTML file from your Files app → Enter a name like "mymoneyapp"
3
Copy Your App URL
You'll get a URL like:
https://mymoneyapp.tiiny.site/money-manager.html
📝 Save this URL — you'll need it below
4
Add to Home Screen
Open your app URL in Safari → Share ⬆️ → Add to Home Screen → Add
Step 2 — Enter Your App URL
Step 3 — Create iOS Shortcut (One Time Setup)
1
Open Shortcuts App
It's pre-installed on your iPhone. Search for "Shortcuts" in Spotlight if needed.
2
Tap "Automation" → "+" → "New Automation"
Choose trigger: "Message" (under Communications)
3
Set Message Filter
• "Message contains" → type: debited
(This catches ALL debit bank SMS)

OR set sender = your bank name e.g. SBIINB, HDFCBK, ICICIBK, AXISBK
4
Turn ON "Run Immediately"
Toggle: Run Immediately = ON
This makes it fully automatic — no manual confirmation
5
Add Action: "Open URLs"
In the action field, build this URL:
YOUR_APP_URL?sms=[Shortcut Input]
Replace Shortcut Input with the variable by tapping the blue + and selecting "Shortcut Input"
6
Tap "Done" — Setup Complete! ✅
Now whenever a matching SMS arrives, the Shortcut will automatically open your Money Manager app with the transaction pre-filled!
